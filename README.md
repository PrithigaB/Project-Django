# Django Task Management API 📝

A decoupled backend system engineered with **Python, Django, and Django REST Framework (DRF)** to provide clean RESTful endpoints for tracking and managing daily activities.

## 🚀 Key Features & Highlights
- **Full CRUD Compliance:** Create, read, update, and delete task records.
- **Data Integrity:** Utilized DRF Serializers for input validation and JSON responses.
- **Relational Database Design:** Managed task allocations using Django ORM on SQLite.

## 🛠️ Tech Stack & Core Endpoints
- **Stack:** Python, Django, DRF, SQLite, Postman
- **Endpoints:** `GET /api/tasks/`, `POST /api/tasks/create/`, `PUT /api/tasks/{id}/update/`, `DELETE /api/tasks/{id}/delete/`
